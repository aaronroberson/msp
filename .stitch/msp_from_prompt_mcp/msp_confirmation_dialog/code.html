Revoke screen recording? CleanShot X · pl.maketheweb.cleanshotx

Revoking this permission will stop the app from capturing the screen. The app will need to re-request access to resume screen recording.

Consequence: any active recording session will be terminated immediately. Audit log entry will be written to /var/log/msp/audit.log.
related command
msp tcc revoke pl.maketheweb.cleanshotx kTCCServiceScreenCapture
